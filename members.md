## Join the Group
We welcome members from:
- Computer Science / AI / Data Science
- Game Development
- Mathematics / Optimization
- Industry practitioners interested in Game AI

> **No prior experience in Game AI is required.**  
> Beginners are welcome — we learn and build together.

### How to join
Please email the following information:

- Name  
- Affiliation / Program / Year  
- Role (Undergraduate / Graduate / Researcher / Industry)  
- Interest areas (2–3 topics)  
- How you would like to participate (learning / project / research / competition)
